# Sinclair Safety Solutions

A recreated static copy of `https://sinclairsafetysolutions.co.uk` for static hosting.

## Project Structure

- `index.html` - static entry point
- `assets/` - production CSS and JavaScript bundle
- `static/` - images and logos referenced by the site
- `sinclairsafetysolutions.co.uk/` - original mirrored download from `wget`

## Run Locally

Serve the folder with any static server:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
